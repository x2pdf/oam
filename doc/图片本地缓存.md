# 远程图片本地缓存

整 App 共用一套图片缓存：同一文档目录、同一套读盘/下载、同一张索引表。主页、收藏、AR 列表、详情、灯箱都走这套机制。Web 不写本地文件，仍直接用 https。

日期：2026-09-26

## 目标

列表里的图在文本中是 HTTP 占位符。渲染时用占位符查本机全路径；文件已在则第一帧用 `file://` 出图，没有才联网下载并写入同一套缓存。

## 结构

```
任一界面卡片
    │
    ▼
peekCachedImagePath(占位符)     ← 启动时从 SQLite 载入内存，兼查目录词干
    │ 命中
    ▼
file:// 直接给 Image
    │ 未命中
    ▼
联网下载 → 写入文档目录 → 写入 image_cache_map → 再给 Image
```

不把这份索引写进 `transactions`、AR `itemJson` 或收藏 JSON。列表对象上的 `cacheMap` 只是展示用的内存快照，真相源是全局表 + 磁盘文件。

## 磁盘

根目录：`FileSystem.documentDirectory + 'oam-remote-images/'`（应用文档目录，不用系统可清的 `cacheDirectory`）。

文件名：`nameFilter(占位符) + '.' + 嗅探到的扩展名`。

- `nameFilter` 去掉 `\ / : * ? " < > |` 和控制字符。
- 词干超过约 200 字符：截断后接短指纹。截断段、指纹、拼好的词干都再走一遍 `nameFilter`。
- 查找：索引里有路径就用；否则在根目录找「词干开头」的一个文件。不按 jpg/png/… 穷举。
- 两张卡同时 miss 允许各下一遍，后写覆盖同名文件。
- 旧版 `cacheDirectory` 里的文件不迁移。

实现：[`src/adapter/remoteImageStore.ts`](../src/adapter/remoteImageStore.ts)

## 索引表

库：`oam_cache.db`。主键是自增 `id`，占位符只做唯一查找键。

```sql
CREATE TABLE IF NOT EXISTS image_cache_map (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  placeholder TEXT NOT NULL UNIQUE,
  localPath TEXT NOT NULL
);
```

- `placeholder`：文本里的占位符原文（不做 `toLowerCase`）
- `localPath`：可直接给 Image 的全路径

启动：`initDatabase()` 之后 `loadCacheMap()` 载入内存；Native 再 `getRemoteImageRoot()` 预热目录列表。

实现：[`src/adapter/cacheMapService.ts`](../src/adapter/cacheMapService.ts)、[`src/storage/database.ts`](../src/storage/database.ts)、[`App.tsx`](../App.tsx)

## 出图

[`useCachedRemoteImage`](../src/hooks/useCachedRemoteImage.ts) 初始 `displayUri` 用 `peekCachedImagePath` / 条目上的 `cacheMap`。命中则第一帧不出转圈。

[`resolveRemoteImageUri`](../src/adapter/remoteImageLoader.ts)：

1. Web：返回 https（可换成网关列表第一项）
2. Native：hint 路径存在 → 用它并回写索引
3. 内存/词干 peek 且文件存在 → 用它
4. 再扫目录词干
5. 都没有才下载（Arweave 按网关列表串行回退）

宽高探测 [`useImageAspectRatio`](../src/hooks/useImageAspectRatio.ts) 只对本地 `file://` / `data:` / `blob:` 调 `Image.getSize`，不对 https 再打网。

解码失败：删该占位的索引行和本地文件，再下一次。用户在 AR 详情下拉刷新仍可通过 `reloadToken` 强制重试；列表刷新不再整表 bump。

## 各界面

| 界面 | 怎么接到这套缓存 |
|------|------------------|
| 主页 | display pipeline 解开 OAMP 后 `hydrateCacheMap`，卡片带上 `item.cacheMap` |
| 收藏 | 快照里可能带 `cacheMap`；即使没有，也查全局 `peekCachedImagePath` |
| AR 列表 | 读出条目后内存 hydrate；写入 AR SQLite 时去掉 `cacheMap` |
| 灯箱 / 保存图片 | 同一套 `resolveRemoteImageUri`；保存时不删 `oam-remote-images/` 源文件 |

清除图片缓存（AR 钱包详情）：清空根目录 + `DELETE FROM image_cache_map`。清主页交易缓存不会清图片索引。
