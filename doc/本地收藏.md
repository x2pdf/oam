# 我的本地收藏

将链上数据详情以快照形式保存在本机，便于离线回看。数据不经过服务器，卸载应用或清除应用数据后会丢失。

日期：2026-08-20

## 功能范围

- **可收藏：** 链上数据条目 `InputDataItem`（主页四个 Tab、地址数据列表进入的「数据详情」）。
- **不收藏：** 订阅地址。订阅本身已是本地列表，与收藏无关。
- **操作入口：** 只在详情页提供「收藏 / 取消收藏」按钮，列表卡片上不放收藏按钮。

同一条数据用 `item.id`（交易哈希）去重。重复点收藏不会新增条目，也不会改变已有顺序。

## 使用流程

```
主页 / 地址数据列表
        │
        ▼
   数据详情页  ──收藏──►  AsyncStorage（本机）
        ▲                       │
        │                       ▼
        └──点击卡片──────  我的 → 我的本地收藏
```

1. 在「我的」页，语言选择卡片之后有「我的本地收藏」入口，副标题显示当前条数。
2. 浏览主页或地址数据列表，进入详情后点「收藏」，该条完整快照写入本机。
3. 已收藏的详情按钮变为「取消收藏」。
4. 收藏列表按收藏时间倒序：最新收藏在顶部。点击卡片进入同一套详情页。
5. 取消收藏后仍停留在当前详情；返回列表时该条已消失。

## 数据模型

```ts
interface FavoriteItem {
  item: InputDataItem;  // 收藏当时的完整快照
  favoritedAt: number;  // Date.now()
}
```

快照包含 `rawInput` / `oampItems` / `textContent` 等展示字段，回看时不再请求链上接口。

存储键：`@oam_favorites`（见 `src/constants/index.ts` 的 `STORAGE_KEYS.FAVORITES`）。旧键 `@onchaindata_favorites` 会在启动时自动迁到新键。

## 状态与持久化

复用 `AppContext` + AsyncStorage，与订阅列表同一套模式。

| 方法 | 行为 |
| --- | --- |
| `addFavorite(item)` | `id` 已存在则忽略；否则插入数组头部 |
| `removeFavorite(id)` | 按 `item.id` 删除，其余顺序不变 |
| `isFavorite(id)` | 判断是否已收藏 |

启动时通过 `AsyncStorage.multiGet` 与订阅、个人资料、API Key 一并加载。`isLoading === false` 后，`favorites` 变化会写回 JSON。

列表顺序完全由数组顺序保证，不做二次排序。

## 界面说明

### 「我的」入口卡

位置：语言选择之后、外观 / 主题之前。

- 图标：`star-outline`
- 标题：`profile.localFavorites`（我的本地收藏）
- 副标题：`favorites.count`（如 `3 条`）
- 点击：`navigate('LocalFavorites')`

### 收藏列表

`LocalFavoritesScreen` 使用现有 `InputDataCard` 渲染，点击进入 `InputDataDetail`。无下拉刷新、无分页。空态提示去详情页收藏。

### 详情页按钮

- 未收藏：`contained`，「收藏」，调用 `addFavorite`，Snackbar「已加入本地收藏」。
- 已收藏：`outlined`，「取消收藏」，调用 `removeFavorite`，Snackbar「已取消收藏」。

无论从主页还是收藏列表进入，按钮都按当前是否已收藏切换。

## 注意事项

- 收藏是设备本地数据，换机、重装、清除应用存储后无法恢复。
- OAMP 等富内容会随快照一起写入 AsyncStorage；条目很多或内容很大时需留意存储体积。
- 收藏后链上数据若有变化，本地仍显示收藏当时的快照，不会自动更新。
